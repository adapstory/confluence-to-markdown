# ADR 0001: Контракт loss-aware конвертации Confluence HTML в Markdown

- Статус: принят
- Дата: 2026-09-04
- Область: `confluence-to-markdown`
- Основание: согласованные ответы Q1–Q27 из проектного обсуждения

## Контекст

Результат конвертации предназначен для последующего чтения LLM, которая получает
только содержимое Markdown. Она не открывает бинарные ресурсы и не участвует в
самой конвертации. Поэтому визуально правдоподобный Markdown недостаточен: потеря
вложения, текста изображения, связи в диаграмме, тела макроса или внутренней
ссылки должна быть обнаружена и явно отражена в результате.

Исходный Confluence работает на Atlassian Confluence 7.19 с Scroll HTML Exporter.
Конвертер запускается локально на корпоративном ноутбуке, где часть необязательных
зависимостей может быть недоступна.

## Согласованные решения Q1–Q27

### Q1 — Основной потребитель Markdown

**Принято:** переносимый GitHub Flavored Markdown для Git, IDE, GitLab и
последующего чтения LLM.

Формат не должен требовать расширений конкретной системы документации.

### Q2 — Граница инструмента

**Принято:** локально принимать готовый экспорт и создавать Markdown. Конвертер
не обращается к Confluence API, не требует учётных данных и не синхронизирует
изменения обратно.

### Q3 — Язык реализации

**Принято:** Python 3.13.

Он выбран для компактной обработки HTML, файлов, XML и архивных форматов Office.

### Q4 — Реальный образец экспорта

**Принято:** квалифицировать конвертер на обезличенном образце, созданном тем же
экспортёром. Образец должен включать содержательные макросы и реальные типы
ресурсов. Рекомендуемый профиль экспорта фиксируется в `README.md`.

### Q5 — Структура результата

**Принято:** один `.md` на каждую страницу, относительные ссылки и отдельные
файлы ресурсов.

### Q6 — Граница страницы

**Принято:** переносить только содержательную часть страницы. Навигация Scroll
WebHelp, поиск, хлебные крошки, боковые панели, служебные скрипты, стили и футер
не входят в Markdown страницы.

### Q7 — Контракт сохранности

**Принято:** создать Markdown, сохранить исходные ресурсы, сформировать отчёт и
завершить запуск ошибкой при любой необработанной содержательной конструкции.

Молчаливое отбрасывание смысла запрещено.

### Q8 — Представление Draw.io

**Принято:** сохранить отрисованное изображение, список узлов, список связей и
исходный `.drawio`.

Текстовая модель должна быть детерминированной и не содержать интерпретаций LLM.

### Q9 — Вкладки и раскрывающиеся блоки

**Принято:** линеаризовать их в Markdown-разделы, сохранив заголовки и всё
содержимое независимо от исходного состояния вкладки или раскрытия.

### Q10 — Отчёт конвертации

**Принято:** вывести сводку запуска в консоль, а ошибки записать в отдельный
файл. Файл может содержать сопровождающие метаданные запуска, но его нормативное
назначение — полный перечень ошибок сохранности.

Отчёт также содержит сведения о локальном окружении и агрегированную сводку
первопричин, чтобы отличать отсутствие инструмента от неполного экспорта,
ошибки исходной страницы, неподдержанного содержимого и дефекта конвертера.

### Q11 — Момент завершения с ошибкой

**Принято:** обработать весь входной каталог, собрать все обнаруженные проблемы
и только после этого вернуть ненулевой код.

Ошибка одной страницы не должна останавливать обработку остальных страниц.

### Q12 — Формат файла ошибок

**Принято:** `conversion-errors.json` со структурированным массивом ошибок.

Каждая ошибка имеет уникальный идентификатор, код, сообщение и доступный
контекст страницы, ссылки или элемента.

Схема версии 2 добавляет обязательные `category` и `action` для каждой записи,
`runtime`, агрегированный `errorSummary`, а для неожиданных исключений — тип и
ограниченный список кадров traceback без локальных переменных и содержимого
документов.

### Q13 — Какие ресурсы копировать

**Принято:** сохранять ресурсы, связанные со страницами, включая исходники
Draw.io. Служебные CSS и JavaScript Scroll WebHelp не копируются как
содержательные ресурсы.

### Q14 — Имена выходных файлов

**Принято:** сохранять относительный путь и имя, созданное экспортёром, заменяя
расширение HTML-страницы на `.md`.

Транслитерация и новое дерево каталогов не применяются.

### Q15 — Допустимый вход первой версии

**Принято:** заранее распакованный корневой каталог экспорта.

Это уточнение заменяет первоначальную рекомендацию принимать ZIP. Конвертер не
распаковывает архив и считает переданный каталог каноническим входом.

### Q16 — Управление Python-зависимостями

**Принято:** `uv`, Python 3.13 и зафиксированный `uv.lock`.

Обязательные Python-зависимости должны оставаться минимальными. Надёжный
HTML-парсер обязателен; Office и Draw.io разбираются стандартной библиотекой;
RapidOCR с ONNX Runtime используется как основной локальный OCR; его три
зафиксированные модели входят в переносимый каталог проекта и проверяются по
SHA-256. Во время конвертации сетевые загрузки запрещены. Tesseract остаётся
явно выбираемым совместимым бэкендом. PyMuPDF остаётся необязательным, а Poppler
служит локальным резервным PDF-бэкендом.

### Q17 — Существующий выходной каталог

**Принято:** автоматически очищать выходной каталог, если он распознан как
результат предыдущего запуска этого конвертера для тех же входного и выходного
путей.

При первом запуске конвертер записывает служебный маркер владения. Результаты
старых версий распознаются по валидному `conversion-errors.json`. Чужой непустой
каталог, символьная ссылка, входной каталог и каталог-предок входа не очищаются.

### Q18 — Граница первой версии

**Принято:** поддержать обычный HTML, стандартные макросы Confluence, Draw.io и
вкладки из предоставленного образца. Неизвестный содержательный макрос должен
попасть в файл ошибок и сделать запуск неуспешным.

### Q19 — Канал данных для LLM

**Принято:** LLM читает только содержимое `.md`.

LLM не создаёт Markdown и не используется для OCR, пересказа или восстановления
пропущенного смысла.

### Q20 — Ссылки

**Принято:** переписывать внутренние ссылки и якоря; считать неразрешимую
внутреннюю ссылку ошибкой; оставлять внешние URL без изменений.

### Q21 — Граница предупреждений

**Принято:** предупреждение допустимо только для визуального отличия. Потеря
смысла, ресурса или ссылки всегда является ошибкой.

### Q22 — Необработанная конструкция внутри Markdown

**Принято:** оставлять заметный маркер с идентификатором соответствующей записи
из `conversion-errors.json`.

Каждое отдельное вхождение ошибки получает отдельный идентификатор.

### Q23 — Текст вложений

**Принято:** извлекать содержимое поддерживаемых вложений непосредственно в
Markdown страницы и одновременно сохранять оригинал.

Поддерживаемая первая версия включает PDF, DOCX, PPTX, XLSX, TXT, Markdown, CSV,
JSON, YAML, EML, HTML, изображения, SVG и Draw.io. Вложенные поддерживаемые файлы
в EML проходят через тот же конвейер извлечения; исходный MIME payload остаётся
в сохранённом оригинале EML.

### Q24 — Обычные изображения и скриншоты

**Принято:** выполнять локальный OCR на русском и английском и помещать текст
рядом с изображением. Нечитаемое содержательное изображение считается ошибкой.

### Q25 — Сложные таблицы

**Принято:** линеаризовать таблицу в явные записи строк и ячеек, сохраняя сведения
об объединениях `rowspan` и `colspan`.

Простая таблица без объединений может оставаться GFM-таблицей.

### Q26 — Где размещать модель Draw.io

**Принято:** размещать список узлов, список связей и ссылку на исходник сразу
после изображения внутри Markdown исходной страницы.

### Q27 — TOC и Children

**Принято:** сохранять оба макроса как обычные Markdown-списки со
скорректированными внутренними ссылками.

## Нормативное поведение запуска

1. Проверить входной и выходной пути до конвертации.
2. Обнаружить все экспортированные страницы по содержательной области.
3. Обработать каждую страницу, продолжая работу после локальной ошибки.
4. Сохранить доступный Markdown и исходные содержательные ресурсы.
5. Вставить в Markdown отдельный видимый маркер для каждого места смысловой
   потери.
6. Записать все ошибки в `conversion-errors.json`.
7. Вернуть код `0`, только если ошибок сохранности нет.
8. Вернуть код `1`, если весь вход обработан, но найдена хотя бы одна ошибка.
9. Вернуть код `2`, если запуск невозможен из-за конфигурации или небезопасного
   файлового пути.

## Критерии приёмки

- Каждая обнаруженная страница имеет отдельный Markdown-файл либо файл с
  маркером ошибки преобразования страницы.
- Все внутренние ссылки ведут на существующую страницу, якорь или сохранённый
  ресурс; каждое исключение зарегистрировано как ошибка.
- Каждый идентификатор ошибки, связанной со страницей, присутствует в Markdown
  и ровно в одной записи `conversion-errors.json`.
- Draw.io, изображения, поддерживаемые вложения, вкладки, раскрывающиеся блоки,
  TOC, Children и сложные таблицы проверяются квалификационным fixture.
- Квалификационный fixture завершается с кодом `0`.
- Структурно неполный экспорт завершается с кодом `1`, сохраняя весь доступный
  результат для исправления источника.

## Последствия

- Неуспешный запуск всё равно создаёт полезный и проверяемый частичный результат.
- Отсутствующая локальная зависимость не может молча уменьшить объём корпуса.
- Код `0` является сильным свидетельством только для конструкций, реально
  представленных в квалификационном fixture.
- Для успешной полной конвертации экспорт должен физически содержать все
  изображения, вложения, внутренние цели и исходники диаграмм.

## Не входит в решение

- Получение страниц напрямую из Confluence.
- Использование LLM при конвертации.
- Сохранение интерактивного поведения вкладок и раскрывающихся блоков.
- Пиксельное воспроизведение оформления Scroll WebHelp.
- Молчаливое принятие неизвестных содержательных макросов.

## Связь с реализацией

- CLI и коды возврата: `src/confluence_to_md/cli.py`.
- Полный проход и запись отчёта: `src/confluence_to_md/converter.py`.
- HTML, таблицы и макросы: `src/confluence_to_md/html_renderer.py`.
- Ссылки и якоря: `src/confluence_to_md/links.py`.
- Ресурсы, OCR и Draw.io: `src/confluence_to_md/resources.py`.
- Вложения: `src/confluence_to_md/attachments.py`.
- Уникальные ошибки и маркеры: `src/confluence_to_md/diagnostics.py`.
- Квалификационный fixture: `tests/fixtures/full-export/`.
